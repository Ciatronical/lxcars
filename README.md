# LxCars

> **Hinweis: Dieses Repository wird nicht mehr weiterentwickelt.**
> LxCars lebt als Erweiterung in **OSERP** weiter.

## Was ist passiert?

LxCars wurde von der Firma **Inter-Data** über viele Jahre als Branchenlösung für
den Kfz-Handel und Kfz-Werkstätten auf Basis von Lx-Office bzw. kivitendo entwickelt.

Die Codebasis dieses Repositorys ist technisch an ihre Grenzen gekommen. Inter-Data
hat LxCars deshalb von Grund auf neu entwickelt und in das Open-Source-ERP-System
**OSERP** integriert. Der gesamte Funktionsumfang von LxCars steht dort als
aktivierbare Erweiterung zur Verfügung, ergänzt um eine moderne Oberfläche,
Buchhaltung, Bankanbindung, CRM und weitere Module.

👉 **https://github.com/Ciatronical/opensource-erp**

## Was bedeutet das für dich?

- **Diese Version nicht mehr einsetzen.** Sie erhält keine Updates,
  Fehlerbehebungen oder Sicherheitskorrekturen mehr. Für Neuinstallationen ist
  sie nicht geeignet.
- **Auf OSERP umsteigen.** OSERP ist der offizielle Nachfolger und wird aktiv
  weiterentwickelt. Die Datenstruktur bleibt kivitendo-kompatibel, sodass
  bestehende Daten übernommen werden können.
- **Erweiterung LxCars aktivieren.** Nach der Installation von OSERP das Modul
  *LxCars* in den Einstellungen einschalten. Damit sind die gewohnten
  Kfz-Funktionen wieder verfügbar.

## Unterstützung bei der Umstellung

Inter-Data begleitet den Wechsel von LxCars auf OSERP, von der Datenübernahme
bis zur Einrichtung. Bei Fragen zur Migration, zum Betrieb oder zum
Funktionsumfang:
